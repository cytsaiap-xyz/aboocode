Launch a dynamic workflow: a JavaScript script that orchestrates many subagents deterministically. The runtime executes the script in the background while the session stays responsive; only the final result returns to the conversation.

The script must begin with `export const meta = { name, description, phases? }` followed by an async body using the globals: agent(prompt, opts?) -> Promise (opts: label, phase, schema, model, isolation, agentType); parallel(thunks) (barrier); pipeline(items, ...stages) (no inter-stage barrier); phase(title); log(message); args; budget; workflow(ref, args) -> Promise (run another workflow inline: ref is a saved name resolved from .aboocode/workflows/<name>.js or { scriptPath }; one nesting level only; the child shares this run's budget, concurrency cap, and abort signal and gets its own journal row).

Date.now(), new Date() with no args, and Math.random() are unavailable (they break resume). Returns { runId, scriptPath }. Resume a prior run with resumeFromRunId.
